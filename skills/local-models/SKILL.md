# Local models on this Mac, through the hub

- **Send requests to `http://localhost:1235/v1`** (the hub's gateway: LM Studio's own API, same paths), never directly to LM Studio's port 1234. The gateway runs admission control across all clients, attributes each request to its project and session, and logs metadata only, never content. Optional headers: `X-Project` (a name), `X-Kind` (`batch`, `chat`, `ask`, `eval`, `test`), `X-Step` (what this request is for, shown on the dashboard). **A batch script also sends `X-Run` (the run's name, the same every time it runs), `X-Run-Total` (units in the whole run) and `X-Run-Done` (units completed)**: the dashboard then shows a progress bar and an ETA, measured on this Mac (`guide section=progress`).
- **Check before you assume.** The `status` tool reports the loaded models, their total concurrent slots, the clients using them now, and any model down after a crash. The `guide` tool gives the full rules (`section=...` for one part).
- **Bulk reading jobs go to local agents**: the `ask` tool (one question, read-only tools scoped to this project's folder, blocks up to two minutes) and `batch` (many jobs in parallel; poll with `job_status`). Their answers are leads to verify, never verdicts: models fabricate quotes and line numbers. `think=false` makes lookups and extraction several times faster; keep thinking on for checks and judgment.
- **A batch should keep as many requests in flight as the loaded replicas have slots** (the `status` tool reports it; the gateway queues the rest). A long run that pauses between requests holds a lease (`guide section=lease`).
- **Never stop LM Studio's server. Never unload or reload a model without `swap_check`**; if it names anyone, do not swap. The simplest swap is `localmodels use <model>` in a terminal.
- **If a model crashes, the instance manager reloads it** within a minute and the gateway holds new requests for it meanwhile; a request that was in flight is resent once, and if the model is still down the gateway returns 503 with `Retry-After`. The instance manager also recycles each instance before the token count at which the engine has crashed, one instance at a time, so a long batch keeps running.
- **Maintenance:** when the hub announces it (a line in the session, the `X-Hub-Maintenance` header, or the `status` tool), do not start a local-model batch that would run past its start; a `503` with `Retry-After` during it means sleep that long and resume (`guide section=maintenance`).
- **See it:** the dashboard at http://localhost:1235 (`localmodels open`), or `localmodels` in a terminal.
- **If the gateway is down** (`status` says so): `localmodels start`. If the tools are missing entirely, the hub is not set up on this Mac yet: `/local-models:setup`.
